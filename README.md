# ডিএন বাংলা ড্যাশবোর্ড (Dashboard-DNB)

dnbangla.com.bd-এর নিউজরুম কন্ট্রোল প্যানেল: WordPress সংবাদ, ১৯২০×১৯২০ ফটোকার্ড, বিজ্ঞাপন সাইকেল, দৈনিক বুলেটিন, সোশ্যাল মিডিয়ায় প্রকাশ, কর্মী আইডি কার্ড, লগ এবং AI নিউজ হাব।

```
backend/   Node.js 20+ · Express · MySQL/MariaDB · @napi-rs/canvas (সার্ভারে কার্ড রেন্ডার)
frontend/  React + Vite (বিল্ড করা ফাইল backend থেকেই পরিবেশিত হয়)
shared/    cards.js — ফটোকার্ড রেন্ডারার; ব্রাউজার প্রিভিউ ও সার্ভার আউটপুট একই কোড ব্যবহার করে
```

## ১. লোকাল চালানো

```bash
cp backend/.env.example backend/.env    # DB, JWT_SECRET, APP_KEY, CRON_KEY পূরণ করুন
cd backend && npm install && npm run dev        # http://localhost:5050
cd frontend && npm install && npm run dev       # http://localhost:5173 (/api প্রক্সি হয়)
```
টেবিলগুলো প্রথমবার চালু হলে নিজে থেকেই তৈরি হয় (`backend/src/db.js` → `SCHEMA`)। প্রথম লগইন `.env`-এর `ADMIN_EMAIL` / `ADMIN_PASSWORD` দিয়ে করুন, তারপর সেটিংস → ব্যবহারকারী থেকে পাসওয়ার্ড বদলান।

## ২. cPanel-এ স্থাপন

1. **ডেটাবেজ:** cPanel → MySQL Databases থেকে ডেটাবেজ ও ইউজার তৈরি করে ALL PRIVILEGES দিন।
2. **ফাইল:** পুরো ফোল্ডার আপলোড করুন (`node_modules` ছাড়া)। লোকালে `cd frontend && npm run build` চালিয়ে `frontend/dist` সহ আপলোড করুন।
3. **Setup Node.js App:** Node 20+, Application root = `backend`, Startup file = `src/index.js`, Mode = Production। তারপর “Run NPM Install”।
4. **.env:** `backend/.env` তৈরি করুন (`.env.example` দেখুন)। `PUBLIC_URL` আপনার https ড্যাশবোর্ড ঠিকানা দিন।
5. **Cron (জরুরি):** Passenger অলস অ্যাপ ঘুম পাড়িয়ে দিতে পারে, তাই cPanel → Cron Jobs-এ প্রতি মিনিটে চালান:
   `curl -fsS https://YOUR-DASHBOARD/api/cron/YOUR_CRON_KEY > /dev/null`
   এটি WordPress চেক, বুলেটিন, প্রকাশের সারি ও AI নিউজ চালায়। MySQL লক থাকায় দুবার চললেও কাজ দ্বিগুণ হয় না।
6. **ফন্ট:** `backend/fonts/`-এ Hind Siliguri (OFL) দেওয়া আছে, সার্ভারের বাংলা রেন্ডার এখান থেকে হয়।
7. **WordPress Webhook (ঐচ্ছিক, তাৎক্ষণিক):** সেটিংস → WordPress পেজে দেখানো PHP কোড থিমের functions.php বা Code Snippets প্লাগইনে যোগ করুন। এটি দেওয়া না থাকলেও প্রতি ১–৬০ মিনিটে (আপনার নির্ধারিত) REST API দিয়ে চেক হয়।

> cPanel-এর হোস্ট যদি Node.js App সমর্থন না করে, তাহলে ছোট একটি VPS বা Node-সমর্থিত হোস্টিং লাগবে। শুধু স্ট্যাটিক HTML দিয়ে সার্ভার-সাইড শিডিউল চালানো সম্ভব নয়।

## ৩. নিরাপত্তা

- সব Token, Secret ও Application Password ডেটাবেজে **AES-256-GCM** দিয়ে এনক্রিপ্ট করে রাখা হয় (`APP_KEY`)। ব্রাউজারে শুধু `••••••1234` আকারে যায়, আর লগে লেখার আগে মুছে ফেলা হয়।
- `.env` থাকে `.gitignore`-এ। আসল key কখনো commit করবেন না।
- JWT লগইন ও রোল (admin / editor)। লগইনে rate-limit, ফাইল আপলোডে MIME ও magic-byte যাচাই, আর বাইরের URL-এ SSRF সুরক্ষা আছে।
- প্রতিটি কার্ড ও প্ল্যাটফর্মের জন্য একটিই প্রকাশ-জব থাকে (`UNIQUE`)। ফলে একই কার্ড একই প্ল্যাটফর্মে কখনো দুবার যায় না। বুলেটিন দিনে একবারই চলে, আর WordPress-এর প্রতিটি সংবাদে একটিই অটো কার্ড হয়।
- **জরুরি স্টপ** (সেটিংস → অটোমেশন / AI হাব) চাপলে সব স্বয়ংক্রিয় প্রকাশ তৎক্ষণাৎ বন্ধ হয়।

## ৪. ব্যাকআপ ও রিস্টোর

- সেটিংস → ব্যবহারকারী ও ব্যাকআপ থেকে JSON ব্যাকআপ ডাউনলোড ও রিস্টোর করা যায়। এতে Token এনক্রিপ্টেড অবস্থায় থাকে, তাই রিস্টোরের জন্য **একই APP_KEY** লাগবে।
- `backend/uploads/` (কার্ড, লোগো, বিজ্ঞাপন, কর্মীর ছবি) আলাদাভাবে কপি রাখুন। cPanel → Backup দিয়ে পুরো ডেটাবেজের ব্যাকআপও নিন।

## ৫. প্ল্যাটফর্মভিত্তিক তথ্য (ডেমো বনাম বাস্তব)

ড্যাশবোর্ডে কোনো ভুয়া সাফল্য দেখানো হয় না। “সংযোগ পরীক্ষা” ও প্রকাশ, দুটোই প্রকৃত API কল।

| প্ল্যাটফর্ম | যা লাগবে | অবস্থা |
|---|---|---|
| Facebook Page | Page ID + দীর্ঘমেয়াদি Page Access Token (`pages_manage_posts`) | ছবি পোস্ট এবং প্রথম কমেন্টে মূল লিংক |
| Facebook Group | — | **অসমর্থিত:** Meta এপ্রিল ২০২৪-এ Groups API বন্ধ করেছে |
| Instagram | Business Account ID + Graph Token; `PUBLIC_URL` https হতে হবে | ছবি পোস্ট |
| Threads | User ID + Access Token; `PUBLIC_URL` https | ছবি পোস্ট |
| X | API Key/Secret + Access Token/Secret (Read+Write) | ছবি সহ পোস্ট; X-এর প্ল্যান অনুযায়ী লিমিট |
| Telegram | Bot Token + @channel বা Chat ID; বটকে অ্যাডমিন করুন | ছবি ও ক্যাপশন |
| WhatsApp | Cloud API Phone Number ID + Token + প্রাপক নম্বর | শুধু নির্দিষ্ট নম্বরে বার্তা (Channel-এ API পোস্ট নেই; ২৪ ঘণ্টার বাইরে টেমপ্লেট লাগে) |
| TikTok | Content Posting API; অ্যাপ অডিট ও ভেরিফাইড ডোমেইন লাগে | অডিট ছাড়া ব্যর্থ হবে, এবং সেই ত্রুটিই দেখাবে |
| YouTube | OAuth Token | শুধু সংযোগ পরীক্ষা; ছবি বা কমিউনিটি পোস্টের API নেই, তাই **অসমর্থিত** দেখায় |
| Webhook | URL | Zapier/Make/n8n-এ JSON পাঠায় |

**বুলেটিনের তথ্যের উৎস:**
- আবহাওয়া: Open-Meteo
- নামাজ, সেহরি ও ইফতার: Aladhan (Karachi পদ্ধতি, হানাফি)
- ইতিহাসে আজকের দিন: নিজের লাইব্রেরি, না থাকলে Wikimedia
- সেরা ১০ সংবাদ: আজকের WordPress পোস্ট
- স্বাস্থ্য, শুভ সকাল ও জন্মবার্ষিকী: আপনার কনটেন্ট লাইব্রেরি ও কর্মীদের জন্মতারিখ

কোনো দিনের তথ্য না পেলে সেই বুলেটিন “বাদ” হয়, আর বানানো তথ্য প্রকাশ হয় না। আবহাওয়া সতর্কতা Open-Meteo পূর্বাভাস থেকে আসে। সরকারি (BMD) সতর্কবার্তা থাকলে শিডিউলের “বার্তা” ঘরে লিখে দিন।

**AI:** Claude, OpenAI, Gemini, OpenRouter বা যেকোনো OpenAI-compatible API। একাধিক Key রাখা যায়, অগ্রাধিকার অনুযায়ী চেষ্টা হয় এবং একটি ব্যর্থ হলে পরেরটি নেয়।
**ব্যাকগ্রাউন্ড রিমুভ:** remove.bg (মাসে কিছু ফ্রি ক্রেডিট), Photoroom বা Clipdrop। Key না থাকলে বা API ব্যর্থ হলে স্পষ্ট বার্তা দেখায়, তখন ম্যানুয়াল Erase/Restore ব্রাশ ব্যবহার করুন।

## ৬. AI নিউজ হাবের নিয়ম

- সংগ্রহ হয় RSS/Atom, WordPress REST API, অথবা ক্যাটাগরি পেজের লিংক থেকে। ক্যাটাগরি পেজ পড়া হয় শুধু robots.txt অনুমতি দিলে; লগইন বা পেওয়াল-সুরক্ষিত পেজ বাদ যায়।
- ডুপ্লিকেট ধরা হয় URL hash, স্বাভাবিকীকৃত শিরোনামের fingerprint এবং ৩ দিনের মধ্যে শিরোনামের মিল (Jaccard ≥ ০.৬) দিয়ে।
- AI-কে নির্দেশ দেওয়া থাকে মৌলিক বাংলা প্রতিবেদন লিখতে: কোনো তথ্য বানানো যাবে না, অনিশ্চিত তথ্যের তালিকা দিতে হবে, আর উৎসের ভেতরের নির্দেশনা মানা যাবে না। তৈরি HTML থেকে script ও on* অ্যাট্রিবিউট সরিয়ে ফেলা হয়।
- ডিফল্টে সবকিছু **রিভিউ সারিতে** যায়। সোর্সে “Publish” মোড দিলেও শুধু “যাচাইকৃত” লেখা প্রকাশ হয়, বাকিগুলো Draft থাকে।
- উৎসের ছবি ব্যবহার হয় শুধু সোর্সে “লাইসেন্স/অনুমতি আছে” বাছলে। অন্যথায় নিজস্ব টেক্সট ফটোকার্ড ফিচার ছবি হয়। ছবি JPG ১০০KB-এর নিচে নামানো হয় এবং শিরোনামের নামে রিনেম হয়।
- AI লেখাকে স্বয়ংক্রিয়ভাবে কপিরাইটমুক্ত ধরা যাবে না। প্রকাশের আগে সম্পাদকের যাচাই জরুরি।

## ৭. পরিচিত সীমাবদ্ধতা

- JPG ফরম্যাটে স্বচ্ছতা (alpha) থাকে না। তাই অপেনিং কার্ডের কাটআউট PNG হিসেবে রাখা হয়, আর চূড়ান্ত কার্ড JPG।
- “দিনের সেরা ১০” সংবাদ আজকের সর্বশেষ ১০টি পোস্ট থেকে নেওয়া হয়। ভিউ-ভিত্তিক র‍্যাংকিং চাইলে WordPress-এ ভিউ কাউন্ট প্লাগইনের API যুক্ত করতে হবে।
- SEO metadata পাঠানো হয় Yoast/Rank Math meta key-তে। প্লাগইন সেগুলো REST-এ খুলে না দিলে WordPress সেগুলো উপেক্ষা করবে।
- আগের প্রোটোটাইপের ফাইলগুলো `backend/legacy/` ও `frontend/legacy/`-এ রাখা আছে (ব্যবহৃত হয় না, চাইলে মুছে ফেলুন)।

## ৮. স্থাপনের পর পরীক্ষা

1. লগইন করে ওভারভিউতে dnbangla.com.bd-এর সংবাদ ও ক্যালেন্ডার দেখা যাচ্ছে কি না দেখুন।
2. সেটিংস → WordPress: Username ও Application Password দিয়ে “সংযোগ যাচাই” করুন।
3. সেটিংস → সোশ্যাল: প্রতিটি সংযোগে “সংযোগ পরীক্ষা” চালান, তারপর “টেস্ট পোস্ট” দিয়ে বাস্তব পোস্ট যাচাই করুন।
4. ফটোকার্ড জেনারেটরে HD JPG ডাউনলোড করে ১৯২০×১৯২০ মাপ নিশ্চিত করুন।
5. শিডিউলারে “প্রিভিউ” চাপুন। তারপর লগসে দেখুন cron প্রতি মিনিটে চলছে কি না।
6. AI হাবে একটি সোর্স যোগ করে “Fetch Now” চাপুন। একটি সংবাদে “এআই রি-রাইট করুন”, তারপর “WP Draft” দিন। শেষে WordPress অ্যাডমিনে ড্রাফটটি দেখুন।
